## Before you open an issue

- Make sure you use the latest version of the project.
- Search the [existing issues](../../issues?q=is%3Aissue), maybe your problem is already known.
- For crashes, upload the full log or crash report to [mclo.gs](https://mclo.gs/) and paste the link.
- One problem per issue.

## Labels

Every issue gets a label for its project (e.g. `project: avies-waypoints`) automatically, so you can filter the issues of one project.
